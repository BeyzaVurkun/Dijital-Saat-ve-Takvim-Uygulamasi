# Dijital Saat ve Takvim Uygulaması
Bu proje, **HTML**, **CSS** ve **JavaScript** kullanılarak geliştirilmiş basit ama şık bir **dijital saat ve takvim uygulamasıdır**.  
Kullanıcıya anlık olarak **saat, dakika, saniye** bilgilerini ve **güncel tarihi** gösterir.  

## Özellikler

- Gerçek zamanlı dijital saat (saat, dakika, saniye)
- Güncel tarih gösterimi (gün / ay / yıl formatında)
- Basit, sade ve modern bir kullanıcı arayüzü

## Teknolojiler
- HTML5
- CSS3
- JavaScript
